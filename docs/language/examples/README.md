# Canonical TOS Core V1 examples

Each `.tos` file here is GPL-3.0-or-later canonical example source for the
accepted TOS Core V1 contract. It is the single source linked by the programmer
guide/tutorial; the prose does not duplicate snippets. The examples are not
generated artifacts and are not executable until a Project Architect accepts
ADR-0028 and the Stage 2 frontend implements the relevant slice.

Examples use `examples.*` module names relative to this directory's accepted
module root. They deliberately do not claim that future Stage 3/4 capability,
IPC, driver, DMA, or service contracts already exist.

The documentation-status matrix records the contract/vector relationship in
[`../EXAMPLE_STATUS.md`](../EXAMPLE_STATUS.md).
