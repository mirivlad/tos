# TOS Core Unicode 17 normalization data

These files are the exact Unicode Character Database 17.0.0 inputs permitted
by ADR-0029 for TOS Core 1.0 NFC validation under UAX #15 Revision 57. They
are semantic data, not a host dependency and not a licence reclassification of
the GPL TOS Core reference implementation.

`PROVENANCE.json` records each source URL and SHA-256. The UCD files and any
derived normalization tables are licensed under Unicode License v3
(`Unicode-3.0`); its required notice is [LICENSES/Unicode-3.0.txt](../../../../../LICENSES/Unicode-3.0.txt).
`scripts/check-tos-core-unicode-provenance.py` verifies the tracked input set.
