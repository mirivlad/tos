## Performance interpretation

ADR-0026 supersedes only the empirically falsified initial 250-ms absolute
estimate.  It does not relax the capsule semantics, resource limits, two
independent validations, trust boundaries or hard architectural budgets.  The
mandatory q35/qemu64/one-vCPU/256-MiB/TCG profile remains a functional
conformance profile and retains absolute median/p95/p99 series as regression
evidence.  The native reference series is retained too.  The hard P2
conformance result is the measured qemu64/TCG full-exact-validation p95 divided
by unavoidable-crypto p95, which the retained artifact verifies is at most
1.30.

## Scope and known limitations

Stage 1 is a bootable trusted-source foundation, not a shell, desktop, general
language runtime, persistent Git implementation, driver stack, recovery
selection system or external-interrupt policy.  The framebuffer Pyro/status
screen is a best-effort post-validation human diagnostic; serial Boot ABI
events remain the machine-readable evidence.  Candidate/last-known-good
selection and rollback remain assigned to Stage 5.  Firmware handoff is tested
on the declared QEMU/OVMF reference profile, not claimed as exhaustive
hardware certification.  These are scope boundaries, not known failures in
the accepted Stage 1 deliverables.
